# FIST OF EIGHT

ブラウザで遊べる2D対戦格闘ゲーム（v0.1 プロトタイプ）。PC・スマホ対応。

## 操作
**スマホ**（横向き）: 左下の方向パッドで移動、右下のボタンで攻撃
- P / K：パンチ / キック　投げ：P+K
- 必殺：ワンボタン必殺技（方向なし / ↓ / ← / → で技が変わる）
- 超必殺：ゲージMAXで発動　タイマー部分のタップでポーズ

**PC**: P1 = WASD移動 / J パンチ / K キック / L 投げ / U 必殺 / I 超必殺、ESCでポーズ

このリポジトリは公開用ビルドです（tools/build_web.js で生成、画像は軽量WebP版）。
